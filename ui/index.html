How It Works

The Science of Invisibility

AphanesKyma uses frequency-domain steganography to hide data imperceptibly inside images.

1. Cover Image

Load any PNG or JPG as the carrier. Larger images hold more data.

2. AES-GCM Encrypt

Your message is encrypted with AES-256-GCM using SHA-256 key derivation from the passphrase.

3. DCT / FFT

The image is divided into 8×8 blocks and transformed to the frequency domain. Mid-frequency coefficients are slightly altered via QIM.

4. Stego Image

Saved as PNG to preserve every modified bit. Visually indistinguishable from the original.

Military-Grade Encryption

AES-256-GCM with random salt & nonce per operation. Even if the stego image is discovered, content remains secret without the passphrase.

Frequency-Domain Hiding

DCT mid-frequency embedding is robust and perceptually invisible. QIM ensures reliable extraction without the original image.

Text & Image Payloads

Hide a typed message or embed an entire secret image inside the carrier. Both are encrypted before embedding.

APKY Magic Signature

Every payload is tagged with the APKY magic bytes + version + type header, enabling validation without trial-and-error.
